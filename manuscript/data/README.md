# Plotting data

Plotting-ready tables for the notebooks in [`../notebooks/`](../notebooks/),
named after the figure they feed (`figNN_<slug>.tsv.gz`). Each file holds only
the rows its notebook plots. Its provenance (upstream source, producing script
and commit, filters, units) is recorded in the notebook's first cells and in
[`../figures_manifest.tsv`](../figures_manifest.tsv).
